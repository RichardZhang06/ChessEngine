# Opening book

`openings.txt` is generated by `tools/build_book.py` from the Lichess opening dataset in `sources/*.tsv`
(https://github.com/lichess-org/chess-openings, released under CC0 1.0). It is compiled into the engine binary by
CMake. To change it, edit or replace the source files, rerun the script, and rebuild.

Format, one line per position: `<piece placement> <side to move> <castling> <uci>:<weight> ...`
