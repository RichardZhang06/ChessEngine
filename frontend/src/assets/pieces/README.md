Each folder in here is a piece "skin" shown in Settings. Put 12 images per folder:

  pieces/<skin-name>/white-pawn.png ... black-king.png

  white-pawn  white-knight  white-bishop  white-rook  white-queen  white-king
  black-pawn  black-knight  black-bishop  black-rook  black-queen  black-king

png, svg, webp or jpg all work. Images placed directly in pieces/ (no folder) form a skin named "default".
